# Patent MCP 冷启动导流钩子

## 一句话钩子（≥5 个方向）

### 1. 结果型 — 说你能得到什么
> 想知道谁手里有能卡住你的专利吗？

### 2. 对比型 — 说不用它之前有多难
> 别等竞争对手告你，才知道他盯了你三年。

### 3. 角色型 — 让 IP 律师对号入座
> 你上一次被客户问'华为这个专利会不会挡我们'，查了多久？

### 4. 数字型 — 用规模制造冲击
> 140,000,000 件

## 排序推荐（按 WorkBuddy Marketplace 场景）
1. → 结果型，4 字目标明确，制造紧迫感
2. → 角色型，唤起痛点记忆（所有 IP 律师都经历过）
3. → 数字型，最短，适合 banner 位置
