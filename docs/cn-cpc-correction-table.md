# CN Patent CPC Correction Table

> 基于 BigQuery `patents-public-data.patents.publications` 实际查询验证。
> 最后更新：2026-06-21

---

## 为什么需要这个表？

BigQuery 的 CPC 分类覆盖对 CN（中国）专利**不完整**。Google Patents 的 CPC 映射对 US/EP/WO 专利准确率高，但对 CN 专利存在系统性偏差。具体表现为：

- 精细 CPC 码（如 `H01L25/065`）对 CN 专利返回 **0 条结果**，但实际上存在数千件相关 CN 专利
- 关键词搜索（中英文）对 CN 专利同样效果不佳（v1.3.1 实测：`query="华为 芯片" + country=CN` → 0 条）
- **CN 专利的唯一可靠搜索路径 = CPC 大类代码**

本表记录已知的 CN CPC 偏差，并提供经过验证的替代方案。

## 已知偏差条目

### 1. H01L25/065 — 先进封装（3D 堆叠）

| 字段 | 值 |
|------|-----|
| **期望结果** | 数千件（中国是全球最大先进封装市场，长电科技/通富微电/华天科技等） |
| **BigQuery 实际** | 0 条 CN 专利 |
| **原因** | BigQuery CN CPC 映射未覆盖此精细分类 |
| **替代方案** | 使用父类 `H01L`（约 15GB/次查询，返回半导体大类全部 CN 专利） |
| **验证命令** | `search_patents(cpc="H01L", country="CN", after="2020-01-01", limit=10)` |

## CN 专利搜索最佳实践

### ✅ 有效路径

1. **CPC 大类 + 国家限定** — 唯一经过验证可靠的 CN 搜索方法
   ```
   search_patents(cpc="G06N", country="CN", after="2023-01-01", limit=10)
   ```

2. **CPC 大类 + 日期范围** — 用于趋势分析
   ```
   search_patents(cpc="H01L", country="CN", after="2024-01-01", before="2024-12-31")
   ```

3. **通用 `get_patent` + `get_patent_claims`** — 已知专利号直接查详情，走 Web 路径（零成本，~1.5s）

### ❌ 无效/不可靠路径

1. **精细 CPC 子类**（如 `H01L25/065`）— CN 覆盖不完整，可能返回 0
2. **关键词搜索**（中英文）— 实测 `query="华为 芯片" country=CN` 和 `query="neural network" country=CN` 均返回 0
3. **仅用国家限定不用 CPC** — BigQuery 无法有效利用 CN 文本索引

## 贡献方法

发现新的 CPC 偏差？

1. 用父类 CPC 确认期望结果量级
2. 用精细 CPC + `country=CN` 测试 BigQuery 返回量
3. 如偏差 > 10x，提交 PR 追加到此表

---

## 局限性说明

- **CPC 映射偏差 ≠ BigQuery 数据错误。** 数据存在（Google Patents 网页版可查到），但 BigQuery 的 CPC 索引未收录
- **本表基于 2026-06-19 实测。** Google 可能在未来更新 CN CPC 映射
- **法律状态不可得。** CN 专利法律状态需要 CNIPA 接口，目前无免费可编程访问路径（详见 docs/cnipa-data-sources.md）
- **权利要求中文版不可得。** Google Patents 网页版提供机器翻译英文版权利要求，但中文原件不可得
